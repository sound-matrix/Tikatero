# Tikatero SEO Phase 09 — Organic growth & measurement

## Shipped changes
- Public event Share dialog can copy a small, visible HTML link to its canonical Tikatero URL, for genuine organisers who want to link from their own website.
- Private/unlisted events do not offer the website-link snippet.
- HTML attributes are fixed; event titles are escaped; slugs strictly validated.
- Existing social sharing and referral analytics remain unchanged; website links contain no tracking scripts.
- Organiser guide now explains a voluntary, relevant link from the organiser website to their published event.
- Unit tests cover canonical URLs, title escaping, malicious/unexpected slugs.

## Search Console measurement routine
1. Open Google Search Console → Performance → Search results, select Search type Web.
2. Record baseline organic clicks, impressions, CTR, and average position over the previous 28 days. Compare against prior 28 days, not daily noise.
3. Inspect Pages: `/organisers`, `/guides/sell-event-tickets-online`, `/events`, and live public events. Compare search queries, impressions and CTR.
4. Refine page titles/descriptions for queries that match a page's real intent and show impressions but weak CTR. Avoid fabricated promises or keyword stuffing.
5. Check Page indexing and XML sitemap processing. Do not request indexing of private/unlisted/hidden events.
6. Revisit after 28 days and correlate changes with event inventory. With every event hidden, the event-related organic growth opportunity is limited.
7. Suggest organisers add a genuine event link on their own relevant website or official announcement. Do not buy bulk backlinks, link exchanges, or spam directories.

No guarantee of specific ranking or traffic growth is implied. Changes do not edit payment or database rules.
