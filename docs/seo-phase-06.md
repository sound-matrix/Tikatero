# SEO Phase 06 — Organiser acquisition and informational content

## Public pages
- `/organisers`: organiser acquisition landing page, key workflow and current pricing link.
- `/organisers/faq`: plain-language answers to organiser questions.
- `/guides/sell-event-tickets-online`: practical evergreen guide for event hosts.

Each page has a unique title, description and canonical URL, and is linked from organiser resources or the public site. URLs are included in the XML sitemap.

## Editorial safeguards
- No invented performance statistics, event counts, fixed pricing, guaranteed payouts, or indexing guarantees.
- Current pricing and payout details are linked to the dynamically maintained pricing page.
- No FAQPage rich-result claims: Google's FAQ rich results are limited to eligible authoritative government/health sites.
- Existing event visibility rules and payment logic are unchanged.
- Articles provide useful, distinct instructions and can remain indexable even when no events are listed.

## Post-deployment
- Check homepage → organisers → FAQ and guide → sign-in navigation.
- Validate mobile layout, accessible headings and canonical URLs.
- Inspect three public pages in Search Console and monitor impressions and clicks.
- Revise content based on actual organiser questions and validated product changes.
